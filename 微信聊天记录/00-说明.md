# 微信聊天记录导出与清洗 · 方案

> 2026-08-27 东哥定:按**联系人**逐个导出、逐个归档(非按设备)。导出后由 Mac 侧 Codex/Claude 提取清洗。
> 安全底线:只处理微信客户端**自带的明文导出**(txt/html);**绝不读微信加密库**(SQLCipher AES-256,逆向/破解一律不做)。

## 一、目录结构(双机都在知识库,自动 Git 同步)

```
微信聊天记录/
├── 00-说明.md              ← 本文件
├── 01-原始导出/
│   └── <联系人名>/         ← 每个联系人一个文件夹
│       ├── Windows-YYYYMMDD.html
│       └── Mac-YYYYMMDD.html
└── 02-清洗后/
    └── <联系人名>.md       ← 结构化沉淀(按人累积)
```

## 二、你手动导出(微信无自动导出 API,只能客户端操作)

**Windows / Mac 同法**:
1. 打开**某个联系人**的聊天窗口 → 右上 `...` → **导出聊天记录**
2. 选时间范围 → 导出(生成文件夹,含 `index.html` + 媒体占位符)
3. 把导出文件夹改名/复制为 `01-原始导出/<联系人名>/Windows-YYYYMMDD.html`
   - 例:`01-原始导出/王东/Windows-20260827.html`
   - Mac 端导出的放 `Mac-20260827.html` 同目录

**原则:一个联系人导一次,就建一个 `<联系人名>/` 文件夹。** 多人就多人多文件夹。

## 三、清洗规则(Codex/Claude 照此执行)

输入:`01-原始导出/<联系人名>/*.html`
输出:`02-清洗后/<联系人名>.md`(同一人多次导出则**追加/合并**,不覆盖)

清洗动作:
- ✅ 提取实质对话文本、决策点、待办、知识点、人名/项目名
- ❌ 剔除:`[图片]` `[视频]` `[表情]` `[语音]` 占位符;系统消息(撤回/拍一拍/入群通知);纯时间戳噪音
- ⚠️ **脱敏**:身份证号、手机号、银行卡、地址等 PII 一律打码(如 `138****1234`)
- 结构:按时间序 + 主题分段;文末留 `来源:01-原始导出/<联系人>/<文件> @ YYYYMMDD`

## 四、调度(总调度派活,清洗在 Mac 侧)

你导出并告知后,我作为总调度:
- **Claude Code**(参谋长):先核 `00-说明.md` 规则,定本次清洗结构
- **Codex**(施工队):`codex exec --approve-for-me` 读取 `01-原始导出/<联系人>/` 提取清洗 → 写 `02-清洗后/<联系人>.md`

## 五、注意
- 导出文件含他人隐私,清洗落库前必走脱敏(见三)
- agent **不碰加密库**,只吃客户端导出明文
