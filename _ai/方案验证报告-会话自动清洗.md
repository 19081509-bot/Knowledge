## 三、真正可行的替代方案

### 3.1 会话清洗怎么做

不用 `file-watcher` 技能，而是：

```bash
# 手动触发 Claude Code 清洗 00_Inbox
claude -p "请读取 /Users/w/Documents/Obsidian Vault/00_Inbox/ 中所有 md 文件，
按 MEMORY.md 规则清洗：去冗余、拆分多话题、打标签、套用模板、
移动到对应分类目录。不要调用任何视觉/图片功能。"
```

### 3.2 禁用视觉模型

OpenClaw 配置中已实现：

```json
"model": "custom-api-siliconflow-cn/deepseek-ai/DeepSeek-V4-Pro"
```

不配 `image` 模型，AI 就不会调用视觉。已生效 ✅

### 3.3 Claudian 关闭 Codex

你已可以在 Obsidian → Claudian 设置 → Codex 标签 → 关闭开关 ✅

### 3.4 当前已实现的自动化
