## 一、MWD绘图软件（近钻头上下伽马，GMCURVE）

### 现场工作流
- 仪器：近钻头上下双伽马；与 DRKX 包共用序列文件 `xulie.tmwd`（392B，另有 xulieold.tmwd）
- 输出：每日打包 200MD.pdf / 200TVD.pdf / 500MD.pdf / 500TVD.pdf + LAS（命名 `井名_日期_MD.las` / `_TVD.las`）
- 200 比例（1:200）→ 给导向师；500 比例（1:500）→ 给录井
- 目录结构：`给录井/` 按日分包；`伽马数据/` 原始；`数据库备用/` 勿删库存
- PDF 转换：内置 PDFdu.PDF.Converter 2.3.0.0 把绘图转 PDF（`PDFdu PDF Converter.exe` 在 Fix 目录）

### 井深关联（已知同套仪器井）
- 庙27-13侧平1井、G104-5P42CP1、G24-P3CP1、C2-P6CP1、G51-15-1CP1
- 与桌面 DRKX 包内 .dat 同名 → 同套近钻头上下伽马仪器

### 输出图像道（draw_*.pdf 版式，1:200 图像测井）
- 左道：MD 刻度；主道：GR IMAGE（0~200）；AZIMUTH_IMAGE（0~360）；DIP ANGLE（0~90 双道）
- 垂直分辨率 >130mm；测点位置 = 扶正器端向上 0.5m

### LAS 输出格式（1.las 实测）
- VERS 2.0（CWLS）；WRAP=NO（每深度一行）；NULL=-999.25
- 曲线道：DEPT.m（测量深度）、TVD.m（垂深）、GRAPI.API（伽马 API）
- 头段：STRT/STOP/STEP、WELL、DATE=240329 等

### V4.8.0 变更（其他/V4.8.0说明.txt）
- 4.8.0：加井斜测深显示记录；井深系统加钻时显示、复测功能；调零长输入；优化伽马绘图；加电阻率绘图
- 4.7.1：修串口缓存；修正测深计算公式
- 4.7.0：伽马 API 最大 500→1000；配合定向探管固件 20191221（未更新固件需用 V4.6.1，伽马基数=环境补偿系数1 会小一半；更新后反之一倍——两者均可用环境补偿系数调回）
- 串口控件：`其他/串口注册/` 以管理员运行 `串口控件注册.bat`（MSCOMM32.OCX 等）

### 绞车/井深标定（操作要点）
- 绞车标定：正转=提升→采样增；大钩最低复位（正转 30000 / 反转 35535）；斜率增、计数/m 减
- 断电恢复法：提方钻杆至方保面对转盘面，大钩高度输 13m 重新对钩位
- 井深计算：方钻杆长 = 方完井深 − 累计钻具长（含方保/下旋塞/接头）；v<0.1m/s 每 0.1m 记，≥0.1m/s 每秒记
- 钩载：坐卡阀值≈方钻杆+单根重；离卡阀值随总钩载调、差值大抗抖；水平井托压 → 勾选"钻头到底+开泵=离卡"
- 井深系统布局/钻时/复测见 V4.8.0

## 二、近钻头伽马探管技术指标（合力）

- 测量范围 0~500API；精度 ±3（0~150）/±10（150~500）；灵敏度 >1.6 计数/API
- 垂直分辨率 >130mm；测速 ≤30m/h；抗冲击 800g，抗振 20g
- API 公式：API = (CPS − 泥浆附加计数) × 标定系数 / 环境补偿系数

|---|---|---|

| 241.3 | 127钻铤/177.8 | 0.32 |
| 311.15 | 177.8 钻铤 | 0.46 |
| 152.4 | 88.9 钻铤/120 | 0.55 |
| 152.4 | 88.9 钻杆 | 0.92 |

### 数据序列与滤波
- 序列 4/5 = 伽马（精度 2）；序列 6 = 温度+电池；组合 = 3 工具面 + 1 伽马
- 伽马 1 米存 4/5/6 点（0.25/0.2/0.17m 间隔）；同深保留最早值；深差超限补无效行"？/*"

## 三、LHE 随钻软件全家桶（定向软件安装包）

### 安装顺序（CONST MWD 教程 4.0.1）
1. 串口驱动：CDM21216_Setup.exe（FTDI 系）
2. .NET Framework 4.6.1（NDP461-KB3102436）
3. 主程序 CONST_MWD.msi（重装只需此步）
- 另有 setup.exe、串口驱动.rar

### 软件清单（顶层）
- LHE0331A.exe、LHE6150R1500Hz.exe（1500Hz）、LHE6267ex.exe、LHE6531B.exe
- LHEGyroSoftware.exe（随钻陀螺）、EMWD System.exe、GeneralPlot.exe、DEES.exe
- duodianoup.exe（多点）、NMDCcalculate（无磁钻铤计算）、ProbeCal（探管标定）、ProbeRollTest（翻滚测试）
- pulser / pulser200（脉冲器）、QC / QClocal、PressureDataColl（压力采集）
- CloudDataUpload（云上传）、hasp_rt.exe（加密狗/HASP 运行时）
- 语言包：各 exe 配 _zh_cn/_english/_russian.qm；多语言 Qt 界面

### 配置要点
- `Config.ini`：项目 001/001.mpf（Landmark 风格路径）；Language=english；`languagep.ini` LANGUAGE=0
- `DBConn.ini`：UseDB=2（本地数据库）；data 用 LHMWD.db / QCData.db / realdraw.db
- `EMSET.ini`："电磁勘探系统 1.4.0"
- `account.ini`：列显示开关+顺序（0~108/1000~1018 列 ID）
- IGRF.COF / WMM.COF（地磁模型）、LH.WITS（WITS 协议映射）、wits.map/witsQC.map、Witsml.config/xml
- `G114-6-CP1`、`LHE6128` 等为井项目目录；`DataUnit.xml` 单位制；`mode.def` 模式定义
- CQZT.ico/LOGO.ico/A1.ico 品牌图标（长庆/西部/合力可换皮肤 qss、titleland.ico）

### 补丁包 temp/deespatch/
- 谱绘 SpectrogramPublish + 测试库；更新器 Update.exe；version.ini
- PluginNodeLHE 系列 DLL（6267/6417/6516/6670/6680/6716/7310/7514C/7611B/7611F/7611K/7613D/8015E/8015F/8015G/8610A/TY，Probe/Probe_B/Probe_C）→ 主机程序按型号加载插件
- ProbeCalTable.ini（标定表）、wellgamma.def（伽马定义）、SysConfig.ini
