# 随钻测量仪器使用与故障排除

> 来源: Qoiltech近钻头说明书 + DRKX陀螺软件 + CONST_MWD + ZY-567H1施工方案
> 更新: 2026-08-09 全面补充

## 一、近钻头测量系统(Near-bit MWD)

### 1.1 系统组成
**发射总成(近钻头短节):**
- 仪器长度: 1050mm
- 外径: 177.8mm(耐磨带184mm)
- 泥浆孔: 60.3mm
- 材料: P550
- 四个模块仓: 电路模块 + 伽马模块 + 电池模块x2

**接收总成:**
MWD探管+适配器+硬连接总成+接收钻铤

### 1.2 安装顺序(自钻头向上)
钻头-发射钻铤(近钻头)-螺杆-接收钻铤-硬连接总成-适配器-PCD探管-螺旋线保护外筒-650脉冲器组件-无磁钻铤-钻杆

### 1.3 电池安装
1. 电池模块装入钻铤安装槽, 引出线走线槽
2. 连接器对插, 聚酰亚胺胶带包裹
3. 检查274密封圈及背圈
4. C型夹同时用力安装盖板
5. 螺钉涂乐泰272胶, 扭矩75N.m
6. 内六角孔涂HZ-1213耐油硅酮密封胶
7. 拆卸前热风枪烘烤使胶失效

### 1.4 工作模式切换
1. 拆读取孔堵头-连接读取工装
2. 软件: 修改串口号-打开串口-连接
3. 设置地面模式-握手-读取版本号-一键井下
4. 安装堵头(乐泰272, 70N.m)

### 1.5 扭力标准
- 盖板螺栓: 75N.m, 乐泰272
- 读取孔堵头: 70N.m, 乐泰272
- 内六角孔: HZ-1213耐油硅酮胶

### 1.6 注意事项
- 电池使用时间: 200h
- 硬连接压缩量: 0.625-1.443英寸
- 内六角间隙大于0.1mm必须更换螺栓
- 拆卸前必须用热风枪烘烤使密封胶失效

## 二、DRKX陀螺MWD系统

### 2.1 用途
- 套管井内陀螺测斜(不受磁干扰)
- 定向井轨迹测量数据采集
- 防碰扫描

### 2.2 软件组成
- DRKX-V2.36/2.42/2.43 主程序
- Config.ini / data.dat / xulie.tmwd
- S模式/C模式选择

### 2.3 陀螺操作流程
1. 连接仪器至USB串口
2. 打开DRKX陀螺软件
3. 配置串口号和参数(波特率等)
4. 陀螺初始化(寻北/定向)
5. 选择模式(S/C模式)
6. 开始测量(下放/上提)
7. 数据存储与导出

## 三、CONST MWD系统

### 3.1 文件组成

## 四、MWD入井前测试

### 4.1 地面测试
1. 连接探管至测试工装
2. 测试三个序列: 测斜/定向/旋转
3. 螺杆测试: 开泵检查震动
4. 检查信号强度和波形

### 4.2 角差测量
内角差: MWD探管与无磁钻铤参考线偏差
外角差: 弯螺杆弯方向与仪器参考线偏差
测量: 激光/水平仪对准, 2人以上计算核对
口诀: 正角差=顺时针, 负角差=逆时针
重要: 每次拆卸重装必须重新测量

### 4.3 下钻注意事项
1. 每下20柱灌浆并测试仪器
2. MWD滤网顺次上移并清洗
3. 泥浆清洁(无编织袋/胶皮)
4. 遇阻不得硬压
5. 严禁加复合堵漏剂(影响MWD工作)

## 五、常见故障排除

| 故障 | 原因 | 解决 |
|------|------|------|
| 无信号 | 电池电量不足 | 更换电池 |
| 信号不稳 | 泥浆含气/泵压不稳 | 调整泥浆/稳定泵压 |
| 井斜不准 | 加速度计零漂 | 重新校准 |
| 方位不准 | 磁干扰/磁偏角错 | 查磁干扰/校磁偏角 |
| 通讯失败 | 串口参数/驱动问题 | 查COM口/重装驱动 |
| 伽马异常 | 探管损坏/放射性干扰 | 更换探管/检查环境 |

## 六、MWD仪器打捞程序
详见 ZY-567H1井定导向施工方案中的完整打捞流程:
1. 打捞条件: 上提拉力大于20t或扭矩大于10kN.m无效
2. 工具: 抽油杆+滚轮扶正器+打捞头
3. 步骤: 对接-遇阻2t上提-标记阻点-起出
4. 注意: 坐卡下放不超过10cm, 距井口50m减速

## 七、防止仪器事故
1. 大于等于1.75度螺杆严禁旋转(只能滑动)
2. 修理时工具面放0度附近活动
3. 禁止长时间转盘活动(防出新眼)
4. 禁止同一井深长时间循环(防大肚子)
5. 每次起钻检查仪器
