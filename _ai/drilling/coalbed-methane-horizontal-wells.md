# 山西煤层气水平井钻井知识体系

> 来源: ZY-567H1/ZY-567H2/ZY-547H1/ZY-558H3 井组设计 + 实际施工方案 + 定向日报
> 更新: 2026-08-09

## 一、山西柿庄南区块地质概况

### 1.1 区域位置
- 沁水盆地东南缘单斜构造, 山西省晋城市沁水县/高平市
- 距太原260km, 距晋城60km
- 中山区地形, 山峦重叠沟壑纵横, 海拔780-1460m(一般1000m)

### 1.2 地层分层
| 地层 | 底界垂深(m) | 厚度(m) | 说明 |
|------|------------|---------|------|
| 第四系 | ~8 | 8 | 地表覆盖 |
| 石千峰组(P2sh) | ~104 | 95 | 上二叠统 |
| 上石盒子组(P2s) | ~591 | 487 | 上二叠统 |
| 下石盒子组(P1x) | ~683 | 92 | 下二叠统 |
| **山西组(P1s)** | **~722▼** | — | **3#煤层目标层** |

### 1.3 煤层特征
- 目的煤层: 3#煤(山西组)
- 煤层厚度: ~6.5m
- 顶板: 薄泥岩层, 上部含砂岩
- 底板: 泥岩, 底板附近发育高伽马夹矸层
- 煤层结构垂向上存在差异
- 易发生掉块、垮塌、卡钻

### 2.2 井眼轨迹设计
- 井型: 水平井(3#煤层)
- 水平段长: 设计892.10m
- 直井段要求: 最大井斜≤1°, 狗腿度≤1.5°/30m
- 造斜率: ~6°/30m
- 着陆: 83°稳斜探煤
- 剖面: J型(直→增→稳→增→水平)

### 2.3 坐标系统
- CGCS2000 / 北京54 两套坐标系
- 高斯-克吕格6°带
- 地质导向使用伽马+电阻率数据

## 三、定向施工关键技术

### 3.1 钻具组合

**二开增斜段:**
Φ215.9mm PDC钻头 + Φ172mm 1.5°单弯螺杆 + Φ172mm无磁钻铤 + Φ172mm无磁悬挂 + Φ127mm加重钻杆×10-20m + Φ127mm钻杆×400m + Φ127mm加重钻杆×300m + Φ127mm钻杆

**水平段(近钻头导向):**
Φ215.9mm PDC钻头 + Φ172mm近钻头短节 + Φ172mm 1.5°螺杆 + Φ172mm接收短节 + Φ172mm无磁悬挂 + Φ127mm加重钻杆×1根 + Φ127mm钻杆 + Φ127mm加重钻杆 + Φ127mm钻杆

### 3.2 钻井参数
- 复合钻进: 钻压40-60kN, 转速30-40r/min
- 定向钻进: 钻压60-100kN
- 排量: 30L/s
- MWD测斜间距: 不超过10m(造斜段加密)

### 3.3 着陆控制(关键工艺)
1. K10层位(标志层): 垂深~591m, 井斜~37°开始对比
2. K8砂岩: 井斜~65°参考标志
3. 桃花泥岩层(铝土质泥岩): 伽马特征明显
4. 1#煤线: K8后薄煤层标志
5. 出2#煤线后调整着陆姿态
6. 留30m稳斜段, 83°左右探煤着陆
7. 要充分考虑地层倾角变化

### 3.4 水平段地质导向
- 使用近钻头伽马(上下双伽马)实时判断位置
  - 上伽马先响应→轨迹上行靠近顶板
  - 下伽马先响应→轨迹下行靠近底板
- 结合钻时、气测、摩阻综合判断
- 保持轨迹在煤层中, 尽量远离顶板
- 勤调整, 减小每次狗腿变化
- 参考等高线+邻井数据预测倾角变化

## 四、近钻头MWD仪器与打捞程序

### 4.1 入井前准备
- 量好MWD与螺杆内外角差(2人以上核对)
- 井口开泵测试: 测斜/定向/旋转三个序列
- 螺杆需震动正常
- 记录所有下井钻具内径, 水眼必须通径
- 丈量仪器上所有阻力点(橡胶扶正块/弹簧扶正器位置和外径)

### 4.2 打捞启动条件
| 条件 | 标准 |
|------|------|
| 能建立循环 | 上提拉力>20t + 扭矩>10kN·m 处理无效 |
| 不能建立循环, 钻具能动 | 处理>8h无效或单凡尔尝试×3次失败 |
| 不能建立循环, 卡死 | 立即启动 |
| 钻具刺漏落井 | 母锥打捞失败后启动 |

### 4.3 打捞工具
- 抽油杆+滚轮扶正器+3个抽油杆吊卡
- 2个打捞头+3个紧扣扳手
- 配套仪器专用提升工具

### 4.4 打捞步骤
1. 计算提升头位置和对接位置
2. 保证钻具接箍接近转盘面(必要时割钻具)
3. 下入抽油杆, 距提升头10m观察悬重
4. 遇阻2t后上提, 标记每个阻点
5. 起出3根后方可卸扣
6. 坐卡时下放不超过10cm
7. 连续3根摩阻无变化→一档平稳上提
8. 距井口50m降低速度
9. 出井后更换专用提升工具

## 五、煤层气钻井风险与对策

### 5.1 井漏
- 随钻加堵漏材料需与定向沟通
- 严禁添加复合堵漏剂(影响MWD工作)
- 必要时起钻换常规钻具堵漏

### 5.2 卡钻预防
- 滑动钻进均匀送钻(正副司钻操作)
- 每柱完确定划眼次数
- 托压摩阻大时: 短起下+拉井壁+倒装钻具
- 确保加重钻杆位于直井段或井斜<30°段

### 5.3 仪器保护
- 接立柱时MWD滤网顺次上移并清洗
- 泥浆清洁, 防止编织袋/胶皮混入
- 修理设备时工具面放在0°附近活动
- 严禁长时间转盘活动(防出新眼)
- 高度数螺杆(≥1.75°)严禁旋转
