# 侧钻开窗技术与钻具扣型

> 来源: 沈275CH方案 + 139.7mm套管开窗程序 + 实际施工经验
> 更新: 2026-08-09 全面补充

## 一、侧钻开窗方式对比

| 方式 | 适用 | 特点 |
|------|------|------|
| 水泥塞侧钻 | 裸眼/套管 | 成本低, 工艺简单, 强度需>=50MPa |
| 斜向器开窗(一趟式) | 套管 | 效率高, 窗口质量好, 一趟钻完成 |
| 斜向器开窗(两趟式) | 套管 | 位置精准, 斜向器座封可靠, 时间长 |

## 二、水泥塞侧钻(沈275CH方案)

### 2.1 水泥塞要求
- 水泥浆: 高强韧性水泥
- 强度: 48h抗压强度>=50MPa
- 高度: 窗口上下各>=50m
- 候凝: >=48小时, 测声幅检查质量

### 2.2 侧钻步骤
1. 通井刮管 - 清理老井套管
2. 注水泥塞 - 封堵老井眼
3. 候凝48h - 测声幅检查
4. 下钻探塞 - 探水泥塞面
5. 定向侧钻 - 使用2度单弯螺杆滑动钻进
6. 确认新眼 - 捞取岩屑判断是否滑回老井

### 2.3 侧钻失败处理
- 捞取老井岩屑判定滑回
- 起钻重新注水泥封堵窗口
- 候凝后重新开窗侧钻

## 三、一趟式开窗(139.7mm套管)

### 3.1 工具组成
斜向器(带座封)+ 铣锥(Whipstock + Mill)

### 3.2 操作流程
1. 下入斜向器+铣锥组合至预定深度
2. 座封斜向器(液压/机械)
3. 启动铣锥开窗(先磨铣套管)
4. 修窗口(上下活动修整)
5. 起出铣锥(斜向器留在井下)
6. 下钻侧钻

### 3.3 优点
- 一趟钻完成座封+开窗
- 窗口位置精确
- 窗口质量好

## 四、两趟式开窗

第一趟: 下斜向器+座封工具-定向-座封-起出
第二趟: 下铣锥-沿斜面磨铣-开窗-修窗-起钻-下侧钻BHA

## 五、钻具扣型知识

| 扣型 | 全称 | 外径(mm) | 应用 |
|------|------|---------|------|
| NC38 | 3-1/2 IF | 88.9 | 88.9钻杆(最常用) |
| NC40 | 4 FH | 101.6 | 101.6高强度钻杆 |
| NC46 | 4 IF | 120.65 | 120.65钻铤 |
| NC50 | 5 FH/IF | 168.28 | 139.7钻杆(大尺寸) |
| REG | Regular | 多种 | 钻头/螺杆连接(方扣) |
| 3-1/2 IF | - | 88.9 | API标准定向钻杆 |
| 4 IF | - | 101.6 | 加重钻杆 |

扣型类型: IF(内平)/FH(贯眼)/REG(正规)/NC(编号)

## 六、BHA设计原则
1. 强度匹配: 各段抗拉/抗扭匹配
2. 造斜匹配: 弯角+距离=目标造斜率
3. 水力匹配: 排量满足螺杆+钻头
4. 磁屏蔽: 无磁钻铤长度足够
5. 通过性: 大曲率井段可通过

### 典型BHA:
直井: 钻头+螺杆+钻铤+钻杆
造斜: 钻头+弯螺杆+浮阀+MWD+无磁钻铤+钻铤+HWDP+钻杆
水平: PDC+1.25度螺杆+浮阀+MWD伽马+柔性短节+无磁钻铤+水力振荡器+HWDP+钛合金钻杆

## 七、侧钻关键操作要点
- 2度及以上螺杆严禁旋转(只能滑动)
- 每次起钻检查螺杆弯角
- 水力振荡器位置按实际调整
- 加重钻杆位于直井段或井斜小于30度段
- 返出岩屑判断: 新地层岩屑=成功, 老井水泥/套管碎屑=滑回
