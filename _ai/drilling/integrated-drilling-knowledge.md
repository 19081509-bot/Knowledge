## 第一篇：钻井工程基础

### 1.1 钻井基本流程
**钻前准备 → 钻进 → 完井 → 投产**

### 1.2 钻井类型
| 类型 | 英文 | 特点 |
|------|------|------|
| 直井 | Vertical Well | 传统方式, 垂直钻进 |
| 定向井 | Directional Well | 按预定轨迹偏离垂直方向 |
| 水平井 | Horizontal Well | 井斜90°沿储层钻进 |
| 超短半径水平井 | Ultra-short Radius Horizontal Well | 造斜率>15°/30m |
| 大位移井 | Extended Reach Well | 水平位移远超垂深 |
| 分支井 | Multilateral Well | 一个主眼多个分支 |
| 侧钻井 | Sidetrack Well | 从老井眼侧钻新井眼 |

### 1.3 钻机八大系统
1. **提升系统** — 井架/天车/游车/大钩/钢丝绳
2. **旋转系统** — 顶驱(Top Drive)或转盘(Rotary Table)
3. **循环系统** — 泥浆泵/地面管汇/立管/水龙带
4. **动力系统** — 柴油机/电机
5. **传动系统** — 变速箱/离合器
6. **控制系统** — 司钻控制台
7. **井控系统** — BOP/节流压井管汇
8. **固控系统** — 振动筛/除砂器/除泥器/离心机

## 第二篇：定向井工程（核心）

### 2.1 基本术语
- **井斜角(Inclination)**: 井眼与垂直线的夹角(°)
- **方位角(Azimuth)**: 井眼水平方向, 正北0°顺时针(°)
- **造斜率(Build Rate)**: 井斜变化率(°/30m)
- **狗腿度/DLS**: 单位长度方向总变化量(°/30m)
- **工具面(Toolface)**: 磁性MTF(<5°井斜) / 重力GTF(>5°井斜, 高边参考)
- **靶点(Target)**: 地质目标(坐标,垂深)
- **垂深(TVD) vs 测深(MD)**: 垂直深度 vs 沿井眼长度

### 2.2 剖面类型
| 类型 | 描述 | 用途 |
|------|------|------|
| Slant(直斜) | 造斜→稳斜 | 简单定向 |
| J-Shape(J型) | 直→增→稳 | 常规/水平井 |
| S-Shaped | 直→增→稳→降→直 | 避开障碍/防碰 |
| 水平井 | 造斜→增至90°→水平 | 水平井 |
| 3D剖面 | 同时增斜+扭方位 | 复杂条件 |

### 2.3 定向工具对比
| 工具弯角 | 造斜率范围 | 特点 |
|---------|-----------|------|
| 1.25°单弯螺杆 | ~5-8°/30m | 复合钻进稳斜 |
| 1.5°单弯螺杆 | ~8-12°/30m | 常用造斜, 可复合 |
| 1.75°单弯螺杆 | ~12-18°/30m | 高造斜(严禁旋转) |
| 2°单弯螺杆 | ~15-26°/30m | 超高造斜(滑动专用) |
| RSS旋转导向 | 0-8°/30m | 全程旋转无托压 |

### 2.4 轨迹控制模式
| 模式 | 特点 |
|------|------|
| 滑动钻进(Slide) | 钻柱不旋转, 螺杆驱动, 可定向, 托压风险 |
| 复合钻进(Rotate) | 转盘/顶驱旋转+螺杆, 稳斜/微增, 钻速高 |
| RSS | 全程旋转+自动导向, 无托压, 成本高 |

## 第三篇：MWD仪器与地质导向

### 3.1 MWD测量内容
**常规MWD:** 井斜/方位/工具面/伽马
**近钻头MWD:** 钻头处上下双伽马, 地质导向关键

### 3.2 地质导向(Geosteering)
使用近钻头上下伽马判断轨迹位置:
- **上伽马先响应** → 轨迹上行靠近顶板
- **下伽马先响应** → 轨迹下行靠近底板
- 结合钻时/气测/摩阻/岩性综合判断

### 3.3 测斜间距标准
| 阶段 | 间距 |
|------|------|
| 常规段 | 每柱(~27m) |
| 造斜段 | 每3-5m加密 |
| 水平段 | 每单根(~10m), 关键段加密 |
| 防碰高风险 | 加密至3m |

### 3.4 磁偏角与坐标
**真北/磁北/网格北:** 磁偏角=磁北与真北夹角, 收敛角=真北与网格北夹角
**口诀: 东加西减**
磁偏角随时间变化, 需定期更新

**常用坐标系:** CGCS2000 / 北京54 / 高斯-克吕格6°带

## 第四篇：钻井液工程

### 4.1 泥浆体系
- **水基(WBM)**: 低成本环保
- **油基(OBM)**: 强抑制润滑好
- **合成基(SBM)**: 环保性能好

### 4.2 堵漏技术
| 漏失程度 | 措施 |
|---------|------|
| 微漏<5m³/h | 随钻桥堵(超细钙/LCM) |
| 中漏5-15m³/h | 配堵漏浆静止承压 |
| 严重>15m³/h | 水泥塞/化学堵漏 |

**重要:** 堵漏材料需与定向沟通, 严禁使用影响MWD的复合堵漏剂

## 第五篇：井控

### 5.1 BOP试压标准
- 环形防喷器: 额定70%
- 闸板防喷器/管汇: 额定100%
- 稳压≥10min, 压降≤0.7MPa

### 5.2 H2S防控
- 固定式+便携式检测仪
- 全员佩戴防毒面具
- 发现立即停工撤离

## 附录：常用公式
**静液柱压力:** P = 0.00981 x ρ x TVD (MPa)
**分离系数:** (中心距 - 误差半径) / 误差半径, SF>1.5安全
**狗腿角(最小曲率法):** β = arccos(cosα1·cosα2 + sinα1·sinα2·cosΔφ)
