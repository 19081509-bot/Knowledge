## 四、网络与端口

| 端口 | 服务 | 说明 |
|------|------|------|
| **4446** | codex-relay | DeepSeek API 中转（Claudian / Codex CLI 调用） |
| **7897** | Clash Verge | HTTP 系统代理 |
| **36677** | PicGo Server | 图床上传接口 |
| **27124** | Obsidian Local REST API | Obsidian 本地 API（HTTPS） |
| **18789** | OpenClaw Gateway | WebSocket 网关（Dashboard: http://192.168.2.67:18789/） |

### ⚠️ 关键网络规则
1. **Clash Verge 必须关闭 TUN 模式**，只用系统代理（127.0.0.1:7897）
2. **运行 codex-relay 时必须退出 Clash Verge**（端口冲突）
3. 局域网 IP（192.168.x.x/10.x.x.x）直连，不走代理

## 九、正确启动顺序

```
1. PicGo — 打开应用（图床后台，端口 36677）
2. Clash Verge — 开启系统代理（关闭 TUN）
3. codex-relay — 终端启动（端口 4446，需退出 Clash）
4. OpenClaw Gateway — 自动 LaunchAgent 启动（端口 18789）
5. Obsidian — 打开（自动加载所有插件，含 Claudian）
```

## 十、故障快速排查

| 问题 | 原因 | 修复 |
|------|------|------|
| Claudian 无图标 | 插件未启用/缓存 | 设置→启用→Cmd+Shift+P→Reload window |
| Claudian 连不上 codex-relay | Clash 抢占端口 4446 | 退出 Clash，重启 relay |
| Claudian 提示 connection refused | API 地址少写 `/v1` | 改为 `http://127.0.0.1:4446/v1` |
| PicGo 不上传 | Server 未开启 | 打开 PicGo→设置→开启 Server |
| 图片上传失败 | PAT 失效/仓库不存在 | 检查 GitHub token |
| Git 推送失败 | PAT 失效 | 重新生成 PAT |
| OpenClaw 不响应 | Gateway 未运行 | `openclaw gateway restart` |
| 视觉模型报错 | 同会话切换模型 | 新建对话，重启 relay |
| 截图粘贴仍是本地路径 | Image Auto Upload 未配置 | 检查端口 36677，重载 Obsidian |
