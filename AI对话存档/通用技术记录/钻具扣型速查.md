# 钻具组合扣型速查

## 基础扣型对照
| 扣型代码 | 标准名称 | 说明 |
|---|---|---|
| 331 | 3½ REG | 三牙轮/PDC 钻头公扣 |
| 330×310 | NC50 (4½ IF) | 螺杆/浮阀/悬挂接头 公×母 |
| 311×310 | NC50 (4½ IF) | 钛合金钻杆/MWD/加重钻杆 公×母 |
| DPDS39 | 101.6mm 专用扣 | DPDS 钻杆专用 |

## 典型 BHA 扣型串联（Φ152.4mm 井眼）

### 裸眼侧钻段
钻头(331) → 单弯螺杆2°(330×310) → 浮阀(311×310) → 钛合金钻杆MWD(311×310) → 悬挂接头(311×310) → 加重钻杆×39根(311×310) → 变扣 → DPDS钻杆(DPDS39)

### 造斜井段
钻头MD617(331) → 单弯螺杆2°(330×310) → 浮阀(311×310) → 钛合金钻杆MWD+GR(311×310) → 悬挂接头(311×310) → 变扣 → 小节箍钻杆×20根(311×310) → 变扣 → 水力振荡器(311×310) → 加重钻杆×39根(311×310) → 变扣 → DPDS钻杆(DPDS39)

### 水平井段
PDC GS616(331) → 单弯螺杆1.25°(330×310) → 浮阀(311×310) → 钛合金钻杆MWD+GR(311×310) → 悬挂接头(311×310) → 变扣 → 小节箍钻杆×45根(311×310) → 变扣 → 水力振荡器(311×310) → 加重钻杆×39根(311×310) → 变扣 → DPDS钻杆(DPDS39)

## 规律
- 钻头统一用 **331** (3½ REG)
- 钻具内部统一用 **NC50** (311×310 / 330×310)
- 变扣出现在：NC50 ↔ DPDS39 转换处
- DPDS39 是 101.6mm 钻杆专用扣型
