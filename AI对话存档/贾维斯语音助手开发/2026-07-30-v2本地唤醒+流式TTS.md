# 🦞 贾维斯语音助手 — v2 重构：本地唤醒 + 流式 TTS

> 日期: 2026-07-30
> 重点: 重写唤醒循环，零 API 本地 VAD 检测 + 流式播放优化

---

## 背景

Codex 版本的 `jarvis-wake.py` 每 5 秒调一次 STT API 检测唤醒词，导致 520 次 API 调用刷爆硅基流动。需要彻底重写架构。

---

## v2 架构

### 唤醒层（Standby）

```
录 2s → VAD 能量检测（纯 Python，本地）→ 安静 → 跳过（零 API）
                                   → 有人声 → SenseVoice API（限流 4 次/分钟）
                                              → 检出"贾维斯"→ 唤醒
                                              → 没检出 → 继续听
```

**关键改进**：
- 唤醒词检测不再每 5 秒调 API
- 先用纯 Python 能量 VAD 过滤（本地，零成本）
- 确认有人说话才调 STT API
- 独立限流：STT ≤ 4 次/分钟，LLM ≤ 6 次/分钟

### 交互层（Active）

```
唤醒 → ▶️ 科幻电子音
     → 连续对话模式（免唤醒）
     → VAD 动态录音（1.5s 块，续录到沉默）
     → SenseVoice STT → DeepSeek V4 → CosyVoice2/TTS → Edge TTS 流式
     → 沉默 10s → ▶️ 退下音效 → 待机
```

### TTS 优化

Edge TTS → 流式播放（ffplay 管道，边下载边播），不再是存文件再播。

CosyVoice2（硅基流动 API）尝试失败：
- 模型名 `FunAudioLLM/CosyVoice2-0.5B` → 返回 `Invalid voice`
- 音色 `anna`、`default`、`中文女声`、`中文男声` 均无效
- 去掉 FunAudioLLM 前缀 → 返回 `Model does not exist`

**TTS 方案回退**：Edge TTS 流式（免费+高质量+流式支持）

## 录音样本

录制了 25 遍"贾维斯"（四川口音变体）存储在 `~/wake-training/positives/`，10 句其他话语 + 环境噪音在 `~/wake-training/negatives/`。

OpenWakeWord 训练因 `onnxruntime` 依赖问题失败（Python 3.14 兼容性问题）。后续改用 VAD + SenseVoice 方案。

---

## 唤醒词匹配

支持四川话口音变体：
```
'贾维斯', '家卫斯', '佳维斯', '嘉维斯', '加维斯', '甲维斯',
'jarvis', 'jia维斯', 'jia卫斯', 'jiaweisi'
```
拼音模糊匹配：含 `jia` 且含 `si/wei/vi`。
