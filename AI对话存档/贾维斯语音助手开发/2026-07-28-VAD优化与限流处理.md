# 🦞 贾维斯语音助手 — VAD优化与API限流处理

> 日期: 2026-07-28
> 重点: 解决唤醒不灵敏 + API 500限流

---

## 🎯 目标

让 wake.py 稳定运行：说"贾维斯"能唤醒并得到回答，静音时不浪费 API 调用。

## 🐛 问题排查

### 症状

重启电脑后唤醒没反应，日志仅显示 `{"event": "transcribing"}`，无任何识别结果。

### 排查步骤

1. ✅ ffmpeg 录音正常（有音频数据）
2. ✅ SenseVoiceSmall API 可连通（手动测试返回 200）
3. ❌ **硅基流动 API 间歇性 500 / 超时**
   - 日志暴露了 `api_exception: Read timed out`
   - 说明 API 服务端不稳定
4. ❌ **旧脚本静默吞错误**
   - `except: return ''` 把全部异常掩盖
   - 用户看到的就是"没反应"

### 修复

| 修复项 | 说明 |
|--------|------|
| 本地 VAD 过滤 | 先检测音频能量再调 API，省 90% 请求 |
| 指数退避 | API 报错后等待 `2^n` 秒再重试 |
| 透明日志 | 所有错误打印到 stdout，方便诊断 |

## 📐 VAD 阈值

基于 MacBook Pro 内置麦实测：

| 音量段 | 环境噪音 | 人声 |
|--------|---------|------|
| >5000 振幅 | 13帧 (0.03%) | 687帧 (1.7%) |
| >10000 振幅 | 极少 | 大量 |

**判断公式**: `moderate > n * 0.008 and strong > 3`
