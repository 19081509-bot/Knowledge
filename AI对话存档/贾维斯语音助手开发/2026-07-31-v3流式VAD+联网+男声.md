# 🦞 贾维斯 v3 — 流式 VAD + 联网 + 男声

> 日期: 2026-07-31
> 状态: ⚡ v3 全链路跑通，后台常驻运行

---

## v3 架构

### 唤醒层（流式 PCM VAD）

```
ffmpeg 管道 → 逐帧 30ms PCM → 能量 VAD
  → 检出人声 → 缓冲到句尾 → STT API
  → 检出"贾维斯" → ▶️ 唤醒音效 → 🟢 ACTIVE
```

**区别**：v2 用 800ms 录音块，v3 用 30ms 帧级实时检测，延迟从 ~6s 降到 ~2s。

### 联网能力

通过 DeepSeek V4 Pro 的 function calling 实现：
- `web_search(query)` → DuckDuckGo API（免费，无需 Key）
- `get_weather(location)` → wttr.in（免费）

### TTS

| 引擎 | 音色 | 效果 |
|------|------|------|
| **Edge TTS** | zh-CN-YunjianNeural（云健·青年男声） | + ffmpeg aecho 科幻混响 |
| macOS say | Tingting 降级 | + ffmpeg 混响 |

## 后台运行

```bash
nohup python3 ~/scripts/jarvis-wake.py > ~/scripts/jarvis.log 2>&1 &
```

PID 记录在 `~/scripts/jarvis.pid`，日志在 `~/scripts/jarvis.log`。
