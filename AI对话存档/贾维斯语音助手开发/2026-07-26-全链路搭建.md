# 🦞 贾维斯语音助手 — 全链路搭建日志

> 日期: 2026-07-26 ~ 2026-07-28
> 状态: ⚡ 全链路联调完成，VAD优化中

---

## 📋 项目背景

在 MacBook Pro (Intel) 上搭建一个类「贾维斯」的中文语音助手，要求：
1. 🎤 说「贾维斯」唤醒
2. 🧠 AI 理解并处理指令
3. 🔊 自然中文语音回答
4. 🔗 能控制智能家居/桌面/浏览器

---

## 🏗️ 架构演进

### Phase 1: Vosk + macOS say ❌

**尝试**: Vosk 小中文模型 (42MB) + macOS say Eddy 语音
**结果**: 失败
- Vosk 中文精度极差，"贾维斯"识别成乱码
- macOS say Eddy 语音机械感重

### Phase 2: whisper.cpp + macOS say ⚠️

**尝试**: 编译 whisper.cpp，下载 tiny/base 模型
**结果**: 精度不足
- Metal GPU 在 Intel Iris Plus 上有 bug（空输出）
- CPU 模式可用但 tiny 模型中文精度不够
- 脚本框架搭建完成（jarvis-stt.py → jarvis-wake.py → jarvis-tts.py）

### Phase 3: 达摩院 SenseVoiceSmall + Edge TTS ✅

**尝试**: 硅基流动 API 调用 SenseVoiceSmall（阿里达摩院开源模型）
**结果**: 成功 ✅
- 中文识别精度极高
- 唤醒词测试通过（"贾维斯今天天气怎么样？😊"）
- 配合 DeepSeek V4 Pro 回答准确
- Edge TTS 微软晓晓自然中文，远超 macOS say

## 🔧 当前问题

### 1. API 限流/500 错误
硅基流动 API 偶尔返回 500 或 timeout，导致脚本不响应。
**对策**: 加本地 VAD 过滤 + 指数退避 + whisper.cpp 本地降级

### 2. 环境噪音触发误识别
MacBook 内置麦克风在安静环境下也有底噪。
**对策**: VAD 阈值调优（>5000 振幅且 >0.8% 帧数才认）

### 3. 唤醒词发音变体
"佳维斯""嘉维斯"等方言/口音发音需匹配。
**对策**: 唤醒词列表扩展 + 拼音模糊匹配

    if has_speech(wav):                # 本地 VAD
        text = transcribe(wav)         # 转录
        if has_wake(text):             # 唤醒词检测
