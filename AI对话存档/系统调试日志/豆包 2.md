## 一、Marvis（腾讯马维斯）是做什么的

Marvis 是 **腾讯自研、系统级桌面全能 AI 智能体成品软件** ，定位电脑 AI 管家，面向国内用户开箱即用：

1. **底层权限** ：直连 Windows/Mac 系统底层 API，不用模拟鼠标点击，直接操控窗口、文件、进程、注册表；
2. **核心能力**
	- 文件全自动化：内容检索、OCR、批量归档、格式转换、清理磁盘；
	- 桌面自动化：打开软件、浏览器操作、批量办公、定时任务；
	- 多 Agent 分工：内置文件、系统、代码、办公、搜索子智能体，自动拆分复杂任务；
	- 双模式推理：云端 API / 本地离线模型，断网可用；
	- 跨设备互通：Windows、Mac、手机互相远程操控；
	- 内置轻度代码生成、执行终端命令，但 **不是专业编程工具** ；
3. **使用门槛** ：纯图形 GUI，不用写配置、不用 Node/Python 环境，下载安装直接用；国内网络无阻碍，免费每日大额 Token 额度。

## 二、Open Claw（龙虾 OpenClaw）是做什么的

OpenClaw 是 **开源自托管 AI Agent 调度框架** ，不是成品软件，是底层路由 / 编排中间件：

1. **核心定位** ：桥梁调度层，本身不带模型，只负责接收指令、分发任务、串联各类工具 / 模型；
2. **核心能力**
	- 多渠道接入：微信、飞书、Telegram、iMessage、浏览器等任意聊天窗口发指令控制电脑；
	- 全开放插件生态（ClawHub），数千社区自定义技能；
	- 调度第三方工具：Codex、Claude Code、本地大模型、数据库、API 服务；
	- 长期记忆、断点续跑、定时后台自动化、自定义复杂工作流；
3. **使用门槛** ：开源代码需自行部署（Node.js 环境、配置 JSON、环境变量），需要基础终端 / 运维能力；自定义自由度极高，但新手折腾成本大。
