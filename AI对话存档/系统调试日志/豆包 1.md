## Obsidian Web Clipper 完整设置（Mac，适配你的 TechVault + 00\_Inbox 收件箱，无 Default Folder 输入框解决办法）

## 一、先说明：新版 Web Clipper 界面改动

新版本插件 **不再单独提供「Default Folder」输入框** ，分两种方式指定默认存入文件夹，二选一即可：

### 方式 A：剪藏弹窗手动固定目录（推荐，永久生效）

1. 打开任意网页，点击浏览器右上角 Web Clipper 图标，弹出剪藏窗口；
2. 在弹窗顶部 `Vault` 确认选择你的库： `TechVault` ；
3. 文件夹下拉框选择 `00_Inbox` ；
4. 勾选弹窗底部 **Remember folder for this vault（记住此库的文件夹）** ；
5. 点击剪藏完成，之后所有剪藏会自动存入 `00_Inbox` ，等效旧版 Default Folder。

### 方式 B：插件设置页面模板写入固定路径

1. 浏览器扩展 → Web Clipper → 点击「Options / 设置」；
2. 找到 `File name template` 下方的 `Content template` ；
3. 在文件路径模板开头强制写入文件夹：

```
00_Inbox/{{date:YYYY-MM-DD}} {{title}}
```

4. 保存，所有新笔记会直接创建在 `00_Inbox` 目录下。

## 二、全套标准参数配置（适配你的会话清洗流程）

### 1\. Vault 库核心配置

- Vault name： `TechVault` （和本地 Obsidian 库文件夹名完全一致，大小写不能错）
- Always use this vault：✅ 勾选，不再每次弹窗选库

### 2\. 文件存储规则（替代 Default Folder）

使用方式 A 勾选「记住文件夹」优先，模板作为兜底： File name template：

```
00_Inbox/{{date:YYYY-MM-DD}}_豆包对话_{{title}}
```

### 3\. 内容模板（适配 OpenClaw 自动清洗，保留完整对话结构）

```markdown
---
source: 豆包
created: {{date:YYYY-MM-DD}}
tags: []
---
# {{title}}
## 原始对话内容
{{content}}
```

作用：提前写入 YAML 元数据，OpenClaw 读取后直接识别为豆包会话，减少 AI 清洗工作量。

### 4\. 功能开关（按下面勾选，避免冲突）

✅ Preserve code blocks（保留代码块，你的报错命令 / 配置不丢失） ✅ Preserve headings（保留标题分层） ❌ Auto-open note after creation（关闭，不用自动弹出，交给 OpenClaw 后台处理） ❌ Use clipboard content（关闭，规避之前 vault 路径编码报错） ❌ Add internal links automatically（关闭，双链由 OpenClaw 统一自动生成，避免重复冗余） ✅ Strip unnecessary UI elements（剔除网页广告、登录弹窗、空白冗余，减轻后续清洗负担）

### 5\. 同步 & 协议设置

- Obsidian URL protocol：✅ 启用
- Clipboard fallback：❌ 关闭（会触发 `vault=00_Inbox` 错误参数）
- Auto-sync delay：3000ms

## 三、找不到 Default Folder 的根源 & 避坑

1. 旧版插件才有独立 Default Folder 输入项，v0.7 + 版本全部整合到剪藏弹窗记忆功能，设置页移除了该输入框，不是缺失功能；
2. 之前 `Vault not found` 报错核心错误：你把子文件夹 `00_Inbox` 填到了 vault 参数里，vault 只能填顶层库名 `TechVault` ，文件夹是二级路径，不能混淆；
3. 校验是否生效：剪藏一条测试对话，打开 Obsidian `00_Inbox` ，能看到新建 md 文件 = 目录配置成功，OpenClaw 会自动监听执行清洗。

## Obsidian Web Clipper v1.7 无文件夹选择入口完整解决方案

## 一、版本界面说明

v1.7 彻底移除了设置页的默认文件夹输入框，文件夹选择仅存在 **剪藏弹出窗口** ，分为两种场景修复：弹窗无文件夹下拉、弹窗能打开但找不到 `00_Inbox` 。

## 方案 1：剪藏弹窗手动指定并永久锁定（优先）

1. 打开豆包对话页面，点击浏览器右上角 Web Clipper 图标，唤起剪藏弹窗；
2. 弹窗顶部第一栏： `Vault` 选择你的主库 `TechVault` ；
3. Vault 右侧就是 **文件夹下拉选择框** ，点击下拉展开目录树，找到并选中 `00_Inbox` ；
4. 弹窗底部勾选： `Remember folder for this vault` （记住当前库的文件夹）；
5. 点击「Clip」完成一次剪藏，之后所有网页会自动存入 `00_Inbox` ，等效旧版 Default Folder。

### 若弹窗里完全看不到文件夹下拉框

1. 确认 Obsidian 软件 **全程保持打开** ，且当前激活库是 `TechVault` ；
2. 关闭 Obsidian，重启后等待插件、图谱全部加载完毕，再打开浏览器剪藏；
3. 刷新浏览器页面，重新唤起 Clipper 弹窗。

## 方案 2：文件名模板强制写入 00\_Inbox（弹窗失效兜底，永久固定）

如果弹窗无法显示文件夹下拉，直接在设置模板里硬编码目录，所有文件强制生成在 `00_Inbox` ，不受弹窗选择限制：

1. 浏览器扩展列表 → Web Clipper → 右键「选项 / Options」；
2. 找到 `File name template` 输入框，完整填入：

```
00_Inbox/{{date:YYYY-MM-DD}}_豆包对话_{{title}}
```

3. 保存设置。

> 原理：Obsidian 文件路径模板开头写文件夹，会直接在该目录创建笔记，不需要手动选择文件夹。

### 配套内容模板（适配你的 OpenClaw 会话清洗）

## 三、找不到 00\_Inbox 文件夹的排查

1. 文件夹名称严格区分大小写，确认库根目录文件夹名为 `00_Inbox` ，不是 `00_inbox` ；
2. 不要给文件夹加隐藏属性，Mac 终端执行解除隐藏：

```bash
chflags nohidden /Users/你的用户名/TechVault/00_Inbox
```

3. 重启 Obsidian、重启浏览器，让 Clipper 重新拉取库内目录树；
4. 若目录仍不加载：Obsidian 内新建任意文件保存，刷新库缓存，再打开 Clipper 弹窗。

截图底部能直接看到灰色输入框 **文件夹** ，就在紫色按钮「添加到 Obsidian」的正上方，这就是设置存入目录的地方。
