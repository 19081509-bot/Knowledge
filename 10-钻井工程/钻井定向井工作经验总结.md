## 一、短半径/超短半径侧钻 · 工艺要点

### 1.1 侧钻开工前准备

- **开窗验收:** 施工前公司、甲方、监理三方做开窗验收,整改不合格项。**所有入井工具要测量内外径及长度**(甲方原话),落鱼事故九成是尺寸、扣型没核清。
- **轨迹数据:** 按原钻机海拔补心高度计算,别中途换基准;设计侧钻点与老井井斜方位不一致时,现场先商量再定。
- **老井资料不可尽信:** 老井标"直井",陀螺一测井斜5°很正常(罗侧53/沈275CH都有);合川112更狠,设计人员把"井斜深"当"垂深"用,靶点垂深偏差6.8m,只能打水泥塞回填侧钻。→ **侧钻点附近一定用陀螺实测,别拿老井方位直接开窗。**
- **工具储备清单:** 斜向器、铣锥(备用)、磨鞋、西瓜铣、领眼磨鞋、扶正器(通井114mm)、钻头(牙轮/三刀翼/五刀翼)、螺杆(无扶/单弯/双弯)、母锥、反扣钻具。每口井开工前列清单,和家里(库房/加工厂)对一次,差的提前补。**开窗铣锥要有备用,问清"完不成开窗备用怎么办"。**

### 1.2 斜向器坐封(关键步骤)

实测流程(重庆短半径/滨105):
1. 陀螺车就位,测陀螺,对好方位,记陀螺摆在高边什么位置。
2. 起电缆。
3. 下斜向器坐封:**打压25MPa,稳压两次;下压8t,过提4t剪断销钉** = 坐封成功。
4. 坐封后下铣锥开窗。

注意:坐封前检查设备能力(现场出现过载车只能上提15t、大泵泵压只能到18MPa,坐封、钻进都费劲的坑);陀螺车占道要先跟气站/通道管理方沟通,别被撵走。

### 1.3 开窗工艺(最关键的参数,记死)

**开窗参数(合川112现场版):**
1. 下钻到底,接触斜向器顶部,下压1~2t确定到底。
2. 上提2m开泵循环顶通。
3. **初始阶段(前0.5m):** 转盘转速30~40转,钻压1t以内,**最大不超过1t**。
4. **过半米后:** 转速提到50左右,钻压2~3t,**最大不超过4t**。
5. 方钻杆还剩4m时全部开完;后段结合实际地层情况再考虑要不要多打。
6. 设计参考排量100~110冲;实际小井眼按现场算。

**开窗节奏实录(重庆短半径):**
- 进尺15cm: 钻压1t、排量10L/s(憋得厉害,不敢加压);
- 钻压慢慢加到3t以上,进尺0.6m、1.2m、1.9m、3.1m一路报;
- 转速70,**总进尺3.5m左右修窗**;完毕起钻换造斜钻具。

**开窗纪律:**
- 开窗时钻台必须留人盯司钻参数,防司钻参数错误。
- 下钻中途及窗口前,**水眼内灌满泥浆**;下入窗口缓慢过窗;距井底1m以上先小排量顶通,再逐渐加大排量(70~80冲),泵压无异常再造斜钻进。
- 钻头水眼易堵(见"螺杆脱胶"),滤清器放好再灌浆。
- 开窗进尺不足、铣锥磨损,别硬打,起钻换铣锥。

### 1.4 短半径钻具组合(记住这几套)

**连续油管侧钻(罗侧53):**
Φ118mm三刀翼PDC钻头(231) + Φ95mm螺杆(1°单弯,230×210) + 89mm无磁承压钻杆 + 105mm悬挂接头 + 配合接头 + 分度工具(103mm,15mm喷嘴) + 85mm加重钻杆×8根 + 马达头总成 + 连接器 + 73mm连续油管。

**超短半径水平井(滨105-17分支2):**
牙轮钻头 + 95mm 1.75°无扶螺杆 + 105mm无磁承压(48mm MWD) + 73mm钻杆到井口。
- 造斜段先下95螺杆+48mm MWD,钻进**5~10m脱离老井磁影响后起钻换双弯**;
- 双弯钻压给不到位的,用"过盈50道"的双弯,扭矩能上来;
- 钻进参数参考:钻压2t、排量10L/s、转速35。

**短半径水平井(合川112):**
钻头118mm + 螺杆88.9mm + 钛合金63.5mm + S135钻杆60.3mm外径,上悬挂接头105mm。大庆专家强调过:**95mm无扶螺杆刚性太强不让下**,要带扶正器或用按要求配的。

### 1.5 钻头选型(短半径专用)

- 五刀翼水眼:4×φ10mm 或 5×φ9mm;头部用奔驰齿,侧面用平圆齿;配三刀翼钻头。
- 尺寸:上接头尽量短(能做到90mm),保径齿长32mm左右,总长12cm上下。
- 要防泥包。加工完要返厂加工钻头装卸器工装,别算漏这个环节。
- 钻头入井前核对扣型(出现过PDC扣型接不上螺杆、临时借钻头的事)。

### 1.6 造斜段轨迹控制

- **造斜率是衡量标准:** 测井要求最大曲率<45°/30m;短半径设计造斜率往45°/30m靠。达不到,基本就是打水泥塞重侧钻的下场(合川112就是33°/30m达不到、打塞重干的)。
- **目标井斜预测:** "预测好井底不用定到设计井斜,预测89°即可复合探井底数据"。先搞清楚**复合钻是增斜还是降斜**——随增斜趋势,初始复合会增斜,注意降垂深复合钻。
- **方位控制:** 方位偏大要降点方位;造斜率高可以复合一点压着打。**每根划好眼。**
- **甲方导向指令:** 甲方按地层倾角给靶点垂深修正(如"地层上倾0.93°,A靶垂深下移0.98m"),照单执行,测斜数据及时上传。
- 造斜率达不到时的对外说辞(记住这句官话): **"根据原有设计方案所使用的造斜工具,已达不到变更设计后的造斜率,我公司正在积极协调造斜率更高的工具。"**

### 1.7 水平段控制

- 稳斜指令常见89~90°。复合钻进单根增0.3~0.8°,连续复合增得猛,压不住井斜时只能靠压钻压控制。
- **短起下是保命动作:** 水平井长水平段,进靶一定井段就组织一次短起(H1井1610m处漏失,领导指令1550m前再短起一次"确保上部井段井眼稳定")。短起上报要写清井段(如"短起下井段1310~870m,上提无挂卡,下放无遇阻")。
- 出层后补救:悬空测钻、控时侧钻(ZY-558H3出煤层后选点悬空测钻,控时侧钻成功)。
- 煤层钻遇率会算:**水平段内煤层段长度/水平段长度×100%**(如857/873≈98.17%)。

## 二、连续油管侧钻(罗侧53井经验)

- 连油侧钻开窗点2422.7m,比较深;地层原因工具面乱跑是常态,靠发指令反复调工具面。
- **分度工具分液控/电控两种:** 液控提前看角度;电控要问清工作模式(能不能打复合等),不了解原理别乱说(当时甲方来人问,我们没敢替厂家吹,只说到时工具来了会有专人指导)。随工具来的新面孔要能讲清工作原理。
- 泵修要单列统计:出现过活塞刺、拉杆断,修了一天,非生产时间要记清楚。
- **连油打捞记录格式:** 下钻至鱼顶深度→开泵泵压/排量→下放加压(如40kN)→上提悬重(最大210kN)→重复打捞N次→判断捞住(上提悬重突变)。判断捞没捞住主要看悬重突变,别拿泵压瞎猜。
- 试压标准参考:桥塞逐级打压坐封;全井筒试压稳压30min,试压合格标准看压降(2360m以上压降<0.5MPa合格)。
- 旧螺杆、钳牙咬痕:新到螺杆刮漆检查有无钳牙咬痕,有咬痕深的返厂处理,**旧螺杆不让下井**。
- 造斜率对不上设计时:实测造斜率(如0.5°螺杆4.5°/30m,设计5.4°/30m,差1个),先跟井下商量,不行就换度数大的螺杆。

## 三、工农关系(老百姓阻工)怎么处理

**沈275CH井活教材:** 这口井因阻工,一周多的有效工期被拖掉。
- 老百姓上井场阻止施工,甚至**80岁老人家上钻台不让施工**。
- 提出要求:施工时间限定"早上8:30~11:30、下午13:30~18:00",**夜间不许施工**。
- 要求甲方赔偿(3方共15万),谈判失败;警察到场协调也没办法。
- 最后逼到"甲方白天必须解决",赔偿谈拢后才恢复施工。

**经验总结:**
1. **阻工不是施工方能解决的**,核心是甲方出面+经济赔偿谈拢。井下/服务方直接跟老百姓谈,谈不拢还容易升级。该推给甲方就推。
2. **限制施工时间是常态**,别硬刚。白天窗口内能干多少干多少,夜间不安排高风险作业。
3. **如实写进日报:** 工况栏写明"老百姓上井场阻止施工,警察协调未果,夜间不让施工,待甲方解决"——让甲方和上级看到进度滞后是阻工造成的(沈275CH每天6:00/14:00两报反复写,就是留证据)。
4. **人身安全第一**,不与老百姓冲突;井场摄像头到处都是,自己劳保穿戴整齐,行为规范。
5. 施工窗口被卡时,把"不发声"的活填进去干:设备检修、井场规格化、候凝。

## 四、钻井监督日报结构(两套模板都记)

### 4.1 油田侧钻/大修类(沈275CH版,9段式)

开头:汇报日期时间/井号/钻井监督+电话/实习监督+电话/建设方/施工单位/钻井队长+电话/设计井深/侧钻点/目前井深/日进尺/目的层位/当前地层。

- **基本头:** 井控评估级别/钻机型号/值班干部及电话/井别/井型/井控级别/搬家时间/动井口时间/侧钻时间/完钻时间/完井时间。
- **一、工程数据:** 设计井深/实际井深/日进尺;目的层位、当前地层、岩性;钻井参数(钻压、转速、排量、泵压、扭矩、钻时、机械钻速);钻头厂家型号尺寸水眼、纯钻进时间、累计进尺;裸眼段长;螺杆厂家型号、使用时间;钻具组合。
- **二、工况:** 按时间段逐段写(如"6:00-9:00下钻至3484m遇阻 → 12:00循环 → 14:00冲划"),复杂如实写。
- **三、下步工况:** 下一班计划。
- **四、钻井液体系:** 密度/粘度/失水/泥饼/含砂/pH/塑性粘度/切力。
- **五、井身轨迹:** 测深/垂深/井斜/网格方位/闭合距/闭合方位/狗腿度°/30m/是否符合设计。
- **六、其他:** 井控设备安装及试压/重晶石储备/邻井停注泄压/防碰情况。
- **七、下套管情况:** 无施工空着或写"无"。
- **八、固井情况:** 同上。
- **九、施工进度:** 设计周期/实际周期/当前周期占比(如"设计66天,实际9.29天,占比14.5%")。

### 4.2 煤层气水平井类(ZY-567H2版,井队简报)

日期/井号/井型/井别/施工队伍/搬迁时间/一开时间/一开完钻/二开时间/二开水平段开始时间/二开完钻/完井时间/设计井深MD/TVD/井深/日进尺/地层/岩性/当前工况(时间段)/钻井参数(钻压、转速+螺杆、排量、泵压)/泥浆性能/测斜数据(测深、井斜、网格方位、垂深、位移、狗腿度)/钻具组合/下一步工作计划/设备类型/天气与路况(是否道路畅通)/井队长/技术员/人员情况(井队、监督、驻井代表、录井、定向、泥浆人数)/备注(造斜点、着陆点、水平段长、煤层段长、煤层钻遇率)。

### 4.3 日报共性原则

- **时间线完整**,几点到几点干什么,别省。
- 起钻或出井发现问题要写(磨鞋磨损、胶皮、钳牙咬痕都算)。
- 短起下要写明井段;天气路况(道路不通/泥泞)写清,影响搬迁运输。
- 数据真实、严禁造假(检查重点);非生产时间(修泵、等仪器)单独统计。
- 井下异常拿不准的,写"现场研究/待措施",别乱下结论(滨105带出的"铜管",有人瞎说套管,被领导骂了)。

## 五、常见复杂情况与应对

### 5.1 仪器故障(短半径最容易栽的跟头)

- **没信号/盲打:** 先盲打试探("盲打两小时仪器还是没信号"→起钻)→起出后震动测试转阀是否正常→井口测试。**井口测试不过关绝不下井。**
- **数据异常:** 连续测斜井斜不对、GT不对、重力工具面不出、只有磁性工具面——基本都是夹表(传感器)或探管问题,直接起钻换探管/脉冲/电池,别扛着打(扛着打井斜超标,完钻电测风险极大)。
- **磁性工具面 vs 重力工具面:** 满工具面、下钻后全是磁性工具面≈仪器有问题。大狗腿(172个狗腿)挤压过后探管反而经用——狗腿大小**不是**夹表报废的决定因素,别瞎甩锅。
- **电池寿命:** 一般约3天(80多小时),下井前记清起用时间;没电地面接电池串再下。
- **备件纪律:** 井上必须留备用脉冲/探管/电池;38mm和48mm仪器各备两串;两个队同开就别共用一套。**仪器问题造成等停,公司名声就完了,现场背锅。**
- 罗侧53应急招:解码乱套→砸开地面管线检查滤网、查泵压;工具面乱→发旋转模式指令。

### 5.2 螺杆故障

- **脱胶(定子橡胶脱落):** 症状是钻头返出胶皮、堵水眼、进尺骤停。脱胶螺杆返厂拆解检查(井上加工不了就找厂家指定的加工厂),别在井上瞎修。用过17小时的旧螺杆、同批次新螺杆要谨慎。
- **旧螺杆不让下:** 现场刮漆检查钳牙咬痕,有咬痕深的返厂处理。
- 入井前测螺杆横向/纵向间隙(约1mm),井口带钻头试运转正常才下。

### 5.3 憋泵 / 堵水眼

- 钻压1t就憋泵 → **小钻压(0.4t)钻进**,憋到不行就起钻处理。
- 防堵:下钻灌满水眼、滤清器放好、小排量顶通再正常钻进。

### 5.4 卡钻 / 粘卡

- 症状:悬重异常、反转无反扭矩、上提悬重上不去。
- 解卡:**高频液动强击器活动解卡**;过提解卡(滨105"过提30t第11次震击才解");粘卡("测斜功夫就粘卡,过提12t才提开")。
- 解不开:起钻,甩反扣钻具,下反扣钻具+公锥倒扣(滨105流程);做好落鱼记录(位置、长度、鱼顶深度)。

### 5.5 打捞作业

- **斜向器打捞:** 领眼磨鞋+西瓜铣;判断捞住看悬重突变(下压8t、上提瞬间悬重17t→26t再回落)。反扣公锥倒扣是最后手段。
- **井内落鱼:** 强磁打捞(井口内残余附件)、铅印打印看鱼顶形状、母锥(打捞范围97~60mm)/捞筒捞小径落鱼。
- 打捞结果必须如实汇报(采油厂对隐瞒落鱼的事很介意),别让甲方从别的渠道知道。

### 5.6 其他井下复杂

- 下钻遇阻 → 冲划、倒划眼处理井壁;套内有残余附件要防下钻进度慢、摩阻大。
- 出层/构造变化 → 复测伽马、和邻井对比、地质循环、起钻等甲方定夺,别自作主张钻下去。

### 5.7 现场管理(检查重点,年年查)

- 井控评估、人员证件(井控证/HSE/硫化氢证/高空作业证,过期一律不许上岗);**应急电话要留全: 地方政府、村里、消防、医疗**。
- 坐岗人员和钻台配硫化氢检测仪,保持通电。
- 工具严禁落地、钻具丝扣保护、井控设备按压力值维护。
- 资料真实、防喷演练提前通知全员参加、交接班签字。
- 井场摄像头到处都是,劳保穿戴整齐(蓝色工服会被点名,红色才合规)。

## 六、可复用经验(干活心得)

1. **工具跟踪是现场工程师的活:** 每口井上井工具和仪器自己盯,缺哪根提前发群里/跟家里要,别等井队催。家里不给就"直接跟我说,我让老板找他们"——工具不到位导致等停,现场挨批。
2. **钻前资料提前做,** 新井没甲方带就按上口井模板做(打造斜段之前必须学会做资料)。
3. **工具好不好用,看大量作业数据,细品。** 每口井记好螺杆、钻头、仪器的使用时间(17h/85h/160h…),攒数据就是攒经验。
4. **进度快慢看钻时:** 钻时慢该歇就歇,一两个小时上去看一趟,拍个照/录个小视频发群里,让领导知道在动。
5. **遇事留痕、如实汇报;** 非生产时间单列统计。
6. **人员轮换:** 两个人别同时死盯,倒班干(测陀螺+坐斜向器干到凌晨6点那种日子要避免连轴转)。
7. **工资、考勤这类事:** 按现场实际记考勤("考勤做到12号,按不待命工况算"),别多记也别少记。
8. 软件安装(Compass/Landmark 5000):老版本卸干净再装新版本,不然装不上;装不上优先查文件是否缺失;备用方案用5000.14。
